# cnu-ai-assistant

충남대학교 심화프로젝트랩 팀 프로젝트입니다. 충남대 학부생용 일정 비서 앱을 만듭니다. 앱 이름은 아직 정하지 않았고, 레포 이름 cnu-ai-assistant를 임시 식별자로 씁니다. 학교 공식 앱이 아닌 학생 프로젝트입니다.

코드는 MIT 라이선스로 공개합니다([LICENSE](LICENSE)). 저작권은 팀원 네 명이 함께 가집니다. 앱에 넣는 글꼴 Pretendard(SIL Open Font License 1.1)와 사용하는 패키지의 저작권 표시와 라이선스 전문은 앱 안 '오픈소스 라이선스' 화면에 표시합니다.

처음 왔다면 [팀원 가이드](docs/guide.md)를 먼저 읽어 주세요. 브랜치를 만들고 PR을 올리는 방법과 Claude Code와 함께 작업하는 요령이 있습니다.
